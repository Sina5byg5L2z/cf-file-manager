下载窗口（单次请求搬运的数据量）
越大请求数越少、下载越快，但单次请求的 CPU 开销线性增长：实测约 25~33ms CPU/MB，超过平台上限的响应会被静默截断。8~16 为推荐区间；调大后页面内下载若遇截断会自动折半重试并给出提示。
「直下阈值」以内的文件由浏览器原生下载：快、文件名可靠，但没有完整性校验；超过的走分片校验路径：三道完整性校验，不过移动端部分浏览器接管 blob 下载时会重命名文件。档位上限 48MB 在平台单响应截断点之下，可放心选择；设为 0 = 所有文件都走分片校验。
设置对所有设备生效；各设备按自身类型自动取对应档位。
歌词
关闭后只使用音频内嵌歌词与手动粘贴的歌词，不发出任何外部请求。译文（含罗马音）目前只有网易云接口提供，需要自行部署 NeteaseCloudMusicApi 并在此填写地址；该地址不会下发给未登录访客。开启后，歌曲名与歌手名会发送给上述第三方服务。
AI 翻译（歌词）
任何 OpenAI 兼容接口均可，改地址 / 模型名 / 密钥后保存即生效，无需重新部署。常用厂商（接口地址 → 模型名示例）：
· 硅基流动 https://api.siliconflow.cn/v1 → Qwen/Qwen3-8B（有免费额度）
· 智谱 GLM https://open.bigmodel.cn/api/paas/v4 → glm-4.7-flash（免费）/ glm-5.1
· DeepSeek https://api.deepseek.com → deepseek-v4-flash / deepseek-v4-pro
· Kimi https://api.moonshot.cn/v1 → kimi-k2 系列；· 阿里百炼 https://dashscope.aliyuncs.com/compatible-mode/v1 → qwen 系列；· OpenRouter https://openrouter.ai/api/v1（一个 Key 通多家模型）。
密钥保存在服务端配置中，不下发给未登录访客；留空则回落服务端环境变量 SILLICONFLOW_API_KEY。翻译按每次约 40 行分批请求，失败会自动拆分重试。
上传前压缩
上传图片 / 视频时先弹窗确认分辨率与画质再压缩，全程在浏览器本地完成（视频优先 GPU 硬件编码，WebCodecs 不可用时自动降级）；压缩结果逐文件确认后才上传，绝不静默替换原文件。关闭后直接上传原文件。此处是弹窗中的默认档位，每次上传时仍可临时更改。
